# Convex Hull Algorithm (2019)

Technologies: Javascript, HTML, CSS

The Convex Hull Algorithm is a computational geometry algorithm that is used to find the convex hull of a set of points in a 2D or 3D space. The convex hull of a set of points is defined as the smallest convex polygon that contains all the points in the set. The Convex Hull Algorithm can be used to solve a wide range of problems in computer science, including collision detection, computer graphics, pattern recognition, and computational geometry.
